### Description 
Weather station application allow the management of weather data from LoRa Weather station in real time. 
Also, it allow the addition, the edition and the removal of stations. In addition, the user can show all weather parameters details in real time and consult the weekly and monthly values.

### How To Use 
- Enter the E-mail ( we can use "admin.admin@sucpom.tn" for the application Test) 
-  Enter the password ( we can use "adminadmin") 
- The Map appear and we can add station ( name, latitude, longitude, Organization name, bucket name, URL, Token...) 
-  Once the station is added, we can select it, and all details are shown (Temperature, Humidity, Rainfall, Light intensity and pressure), and when we click on the widget, we find the weekly curves) also we can add it as a favorite station.
- In the settings, we find "Report problem", and Notifications.
